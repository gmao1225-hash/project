# 🍽️ 한끼맛집 — 맛집 & 가성비 식당 웹페이지

빌드 도구 없이 동작하는 정적 웹페이지입니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 기능
- **탭**: 전체 / 💰 가성비 / ⭐ 맛집(평점 4.5↑) / ❤️ 찜
- **검색**: 식당 이름, 지역, 카테고리, 태그
- **필터**: 카테고리(한식·일식·중식…), 최대 가격
- **정렬**: 추천순(가성비 점수), 평점, 가격, 리뷰 수
- **찜하기**: 브라우저(localStorage)에 저장
- **상세 보기**: 카드를 클릭하면 영업시간·가성비 점수 표시
- 모바일 화면 및 다크 모드 지원

## 구조
```
index.html      페이지 마크업
css/style.css   스타일
js/data.js      식당 데이터 (샘플 — 여기를 수정하세요)
js/app.js       검색/필터/정렬/찜 로직
```

## 식당 추가하기
`js/data.js`의 `RESTAURANTS` 배열에 항목을 추가하세요.
가성비 점수는 평점(60%)과 가격(40%)으로 자동 계산됩니다. 1인 1만 원 이하이거나 `value: true`인 식당에 가성비 배지가 붙습니다.
